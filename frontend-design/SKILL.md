# Frontend Design

Ao criar interfaces:
- Use HTML semântico (header, main, section, footer)
- CSS moderno: Flexbox, Grid, variáveis CSS
- Mobile-first com media queries
- Tipografia: no máximo 2 fontes, hierarquia clara (h1-h6)
- Espaçamento consistente (sistema de 8px)
- Paleta: 1 cor primária, 1 secundária, neutros
- Contraste mínimo AA (4.5:1 para texto)
- Microinterações sutis (hover, focus, transições 200ms)
- Modo escuro quando aplicável
