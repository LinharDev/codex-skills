# Web Design Guidelines

Princípios:
- Hierarquia visual clara (título > subtítulo > corpo)
- Whitespace generoso — não amontoe elementos
- Máximo 3 cores + neutros
- Imagens otimizadas (WebP/AVIF, lazy loading)
- Navegação intuitiva (máx 7 itens no menu)
- CTAs visíveis e contrastantes
- Loading states e empty states sempre previstos
- Feedback visual em todas as interações
- Acessibilidade: alt text, labels, navegação por teclado
